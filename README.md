# Seminário — Case OpenAI: a era da inteligência generativa

Apresentação interativa em HTML para o seminário **Cases de Inovação em Tecnologia**
(Inovação e Criatividade · Bacharelado em Engenharia de Software · Prof. Francisco Petrônio Alencar de Medeiros).

**Dupla:** Ícaro e Diogo · **Duração:** cerca de 18 minutos · 23 slides em 5 atos + conclusão.

## Como abrir

- **Online:** pelo GitHub Pages deste repositório.
- **Offline:** baixe o `index.html` e abra no Chrome ou Edge. É um arquivo único, com fontes, dados e animações embutidos: não precisa de internet.

Para apresentar, use o navegador em tela cheia (tecla **F**).

## Teclas

| Tecla | Ação |
|---|---|
| → · Espaço · PageDown (ou passador de slides) | avançar |
| ← · PageUp | voltar |
| N | janela de notas do apresentador (fala atual, próximo clique, cronômetro) |
| B | tela preta |
| F | tela cheia |
| R | desligar/ligar animações |
| 1–6 | pular para o ato |
| H | ajuda |
